---

2) O que o node e o npm são? 🤔

   - Node é um ambiente de execução do javascript fora do navegador

   - npm é um gerenciador de pacotes que vem junto com o node, ele instala, atualiza e gerencia bibliotecas feitas pela comunidade 😎
    (npm install express) -> exemplo: isso baixa uma biblioteca pronta pra você usar no seu projeto

   - ou seja, node é o ambiente de execução (do js fora do navegador) e npm é a lojinha que você baixa e integra bibliotecas no seu projeto. Por isso o node é baixado apenas uma vez, mas bibliotecas como express e mongoose são instaladas em cada projeto individual 
    (existe forma de instalar global, mas por enquanto o importante é saber apenas a base)
