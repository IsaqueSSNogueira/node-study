1) Crie um arquivo base

```
  const express = require("express");
  
  const app = express();
  const PORT = 3000;

  // permite receber JSON
  app.use(express.json());

  // rota principal
  app.get("/", (req, res) => {
  res.send("Servidor Express funcionando 🚀");
  });

  // iniciar servidor
  app.listen(PORT, () => {
    console.log(`Rodando em http://localhost:${PORT}`);
  });

```


---

2) Destrinchando cada comando

  --> const express = require("express"); 🚀
      (importa biblioteca express que está em node_modules e coloca numa variável chamada express)
   
      ...há um outro jeito de se importar, no padrão ES Modules, o mesmo do react.js:
  
  --> import express from 'express' 🚀
	 (só precisa avisar ao package.json que seu projeto utiliza este formato, marcando type:module)
         (import segue o padrão js moderno, enquanto o require segue o padrão antigo do node - CommonJs)



  --> const app = express 🚀
      (cria uma aplicação Express, que na prática é:
         - um servidor http configurável; 
	 - objeto que recebe requisições;
         - centro de controle do backend (cria rotas, usa middlewares, inicia o servidor)



  --> const PORT = 3000 🚀
      (uma porta é um canal de comunicação do computador)
      (quando você acessa http://localhost:3000, você indica que quer falar com o serviço que está na porta 3000)



  --> app.use(express.json(()) 🚀
      (ele permite que o servidor entenda os dados enviados pelo cliente)
      (sem isso, se um app enviar dados (que vem em json), o express não vai saber interpretar)
      (ele é um middleware, um processamento que roda antes das rotas)


  --> app.get("/", (req, res) => {...}) 🚀

      (get - requisição do tipo "cliente quer obter dados)
         ..outros tipos comuns: post (enviar dados), put (atualizar dados), delete (remover dados)

      ("/" - caminho da url)
	 .."/users": http://localhost:3000/users

      (req - pedido do cliente)
         ..contém: dados enviados, parâmetros da url, cabeçalhos, info do navegador

      (res - é a resposta do servidor)
         ..você usa para: enviar texto, enviar JSON, enviar arquivos, definir status (200, 404, etc.)


      (res.send(...))
        ..enviar uma resposta ao cliente:
          - se for texto, renderiza no navegador
          - se for objeto, vira JSON



  --> app.listen(PORT, () => {...}) 🚀
      (faz o servidor começar a ouvir as requisições, abre a porta definida e mantém o processo rodando)
         ..sem isso o servidor existe, mas não está ativo, ninguém consegue se conectar
	 ..console.log() não conecta nada, mas é uma mensagem de confirmação para você saber que funcionou
      (é tipo como se o servidor dissesse "se alguém falar pela porta 3000, eu respondo)
